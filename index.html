使い方
V 選択 / P ペン / M マーカー / L 直線 / A 矢印 / R 四角 / O 丸 / T 文字 / E 消しゴム
選択ツール：クリックで選ぶ → ドラッグで移動、四隅・辺の□をドラッグで拡大縮小（角＋⇧で縦横比キープ）。何もない所からドラッグで囲み選択、⇧クリックで追加選択。文字はダブルクリックで書き直せます。
文字ツール：すでにある文字をクリックすると書き直せます。Enter で確定、⇧Enter で改行（漢字変換の確定 Enter では閉じません）。
⌘Z 戻す・⇧⌘Z やり直す / Delete 選択を削除
[ ] 太さ / 1〜6 色
space+ドラッグ・ホイールで移動、⌘ホイールで拡大縮小
⌘0 全体表示 / ⌘1 等倍 / ←→ ページ移動
ページの複製：サムネイルの ⧉ か ⌘D（赤字ごとコピーして隣に追加。書き比べに便利です）
消しゴムは線を1本ずつ消します。
Apple Pencil・ペンタブの筆圧に対応（ペン使用中は指では描かず画面移動になります）。
画像を読み込むとここにページが並びます
